# ML-агент для табличных задач

LLM-агент на LangGraph, который сам решает задачи регрессии и классификации: читает описание задачи, пишет код экспериментов, запускает их и сохраняет лучший сабмит. Человек в процессе не участвует.

Делал для хакатона, итог - **12 место**.

## Как устроен

Граф из пяти узлов:

- `analyze` - читает `task.md` и данные, определяет id, таргет, тип задачи и метрику, строит фолды и краткий профиль признаков для промпта
- `generate` - LLM пишет полный скрипт эксперимента
- `tools` - скрипт запускается в отдельном процессе, в своей папке и с таймаутом
- `evaluate` - проверяет `oof.csv` и `submission.csv` и сам считает метрику по OOF; если стало лучше, обновляет ответ
- `nudge` - срабатывает, если модель ответила текстом без вызова инструмента

Цикл идёт, пока не кончится время, 25 экспериментов или 6 запусков подряд без улучшения.

Что больше всего помогло:

- фолды создаются один раз и общие для всех экспериментов, иначе скоры несравнимы
- метрику считает код, а не модель: LLM только присылает предсказания
- если test - более поздний период, чем train, валидация идёт по группам (GroupKFold по колонке периода)
- подозрительно идеальный скор помечается как возможная утечка таргета
- в контексте остаются промпт, задача и последние шаги, плюс журнал и код лучшего эксперимента
- если модель прислала код в markdown вместо вызова инструмента, он всё равно запускается

## Запуск

Python 3.12, любая LLM с OpenAI-совместимым API (на хакатоне была Qwen).

```bash
python -m venv .venv && source .venv/bin/activate
pip install numpy==1.26.4 scipy==1.12.0 pandas==2.2.3 scikit-learn==1.5.2 \
    lightgbm==4.6.0 catboost==1.2.8 xgboost==2.1.4 \
    openai==1.68.2 httpx==0.28.1 langchain==0.3.27 langchain-openai==0.3.23 langgraph==0.6.7 \
    python-dotenv==1.0.1
cp .env.example .env
```

`train.csv`, `test.csv` и `sample_submission.csv` кладутся рядом с `task.md`:

```bash
TIME_LIMIT_SEC=1200 python solution.py data/regression/task.md
```

На Windows: `powershell -ExecutionPolicy Bypass -File run.ps1 regression 20`

Ответ сохраняется в `data/<задача>/submission.csv`, код и логи каждого эксперимента - в `data/<задача>/experiments/`.

`requirements.txt` - полное окружение платформы хакатона, для запуска хватает списка выше.

## Задачи

В `data/` лежат описания двух задач с хакатона и словари признаков. CSV не добавлял из-за размера.

- `regression` - годовое энергопотребление зданий, RMSE. Test - более поздние годы.
- `classification` - типы сетевых атак (UNSW-NB15), 10 классов с сильным дисбалансом, Macro F1.

## Файлы

- `solution.py` - точка входа
- `agent_graph.py` - граф и маршрутизация
- `agent_nodes.py` - узлы графа
- `agent_tools.py` - инструменты агента
- `agent_task.py` - разбор задачи, метрики, фолды, проверка сабмитов
- `agent_prompts.py` - промпты и baseline
- `agent_config.py` - лимиты и настройки
